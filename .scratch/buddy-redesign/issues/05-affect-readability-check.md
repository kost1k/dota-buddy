# 05. Проверка читаемости аффекта

Status: ready-for-human
Type: research
Blocked by: 04

## Зачем

Ворота между рубежом 1 и всем остальным. Проверяется **не то, работает ли
код**, а то, работает ли продуктовая гипотеза: читает ли состояние бадди
человек, который про Доту ничего не знает.

Задача для человека: нужны люди, а не тесты.

## Что сделать

1. Показать бадди в нескольких характерных точках плоскости (пресеты из
   тикета 03) **минимум двум людям, не знающим Доту**.
2. Не подсказывать и не объяснять модель. Вопрос открытый: «что с ним
   происходит?»
3. Отдельно проверить независимость осей: показать две точки, различающиеся
   только по `valence`, и две — только по `arousal`. Спросить, в чём разница.
4. Записать формулировки дословно — важно не «угадал / не угадал», а какими
   словами человек описывает состояние.

## Критерий приёмки

- [ ] Знак `valence` («у него всё хорошо» против «всё плохо») угадывается без
      подсказок
- [ ] Уровень `arousal` («спокоен» против «на нервах») угадывается без
      подсказок
- [ ] Две точки, различающиеся по одной оси, описываются по-разному

## Если не прошло

Переделывать **форму**, а не добавлять слои. Порядок жертв из спеки §8 здесь
неприменим — он про перегрузку каналами, а тут каналов ещё нет: две оси
неприкосновенны, значит проблема в том, как форма их выражает.
