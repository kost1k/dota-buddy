# 07. Пульт, уровень снапшотов

Status: ready-for-agent
Type: task

## Зачем

Верхний уровень пульта (тикет 03) дёргает оси напрямую и **не проверяет
серверный вывод событий вовсе** — а это самая ошибкоёмкая часть системы и
единственная, которую на машине разработки иначе не проверить ничем: ни
Доты, ни OBS здесь нет.

Нижний уровень собирает синтетические GSI-пакеты и шлёт их в
`POST /api/gsi`, после чего всё идёт штатным путём: санитизация, вывод
событий, WebSocket, отрисовка.

## Что сделать

1. Конструктор снапшота: здоровье, мана, уровень, жив/мёртв, килы, смерти,
   килстрик, аганим, шард, станы и дебаффы, время матча.
2. Отправка в `POST /api/gsi` — тем же путём, что и настоящая игра.
3. Сценарии в одно нажатие: получил урон, умер, респавн, забрал килстрик,
   собрал аганим. Сценарий — последовательность снапшотов с паузами, а не
   один пакет: реальная игра шлёт поток.
4. Темп отправки регулируется, по умолчанию ~1 Гц — реальная каденция GSI.

## Критерий приёмки

- [ ] Пакеты уходят на сервер и возвращаются событиями по WebSocket
- [ ] Сценарий «умер и возродился» проходит целиком без ручной сборки
- [ ] Формат снапшота совпадает с форматом записи (тикет 10)
