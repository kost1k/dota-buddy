# Концепция: Dota Buddy Overlay

## Идея

Dota Buddy - реактивный стрим-оверлей, который визуально отражает интенсивность игры и ключевые игровые события в реальном времени.

## Текущий продуктовый фокус

- Живой 3D-аватар/ядро, меняющее поведение от состояния матча
- Компактная карточка метрик (GPM/XPM + streak)
- Минимальная задержка между GSI событием и визуальным откликом

## Текущая модель состояний

- `update` - регулярное обновление статистики игрока/героя/карты
- `death` - специальное состояние при `hero.alive === false`
- Derived UI state:
  - `sweatLevel` (0..100)
  - `currentStreak`
  - `showLevelUp`

## Следующий этап концепции (план)

1. Event-driven события матча:
   - `first_blood`, `multi_kill`, `roshan`, `aegis_pickup`, `buyback`
2. Режимы отображения для OBS:
   - `compact`, `minimal`, `cinematic`
3. Интерактив стрима:
   - Wall of Grief
   - Twitch-команды (`!mode`, `!bet`, `!vote`)
4. Персистентность:
   - локальные сессионные метрики и лидерборд
