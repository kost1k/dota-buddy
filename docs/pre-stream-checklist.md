# Pre-Stream Checklist

Быстрая проверка перед запуском стрима с `Dota Buddy`.

## 1) Сервер и окружение

- [ ] Установлены зависимости: `bun install`
- [ ] Создан и заполнен `.env` (на основе `.env.example`)
- [ ] Приложение запущено: `bun run dev` или production-режим
- [ ] Health endpoint отвечает: `GET /api/health` возвращает `status: "ok"`

## 2) Конфигурация сети и WS

- [ ] `NUXT_PUBLIC_WS_URL` указывает на рабочий endpoint (`ws://.../ws` или `wss://.../ws`)
- [ ] Overlay-страница открывается без ошибок в консоли
- [ ] В `/api/health` поле `wsPeers` > 0 после открытия overlay

## 3) Безопасность GSI

- [ ] Для `POST /api/gsi` задан `NUXT_GSI_SECRET` (если нужен защищенный режим)
- [ ] В GSI-конфиге Dota указан тот же `auth.token`
- [ ] При неверном токене сервер отдает `401`, при верном - `200`

## 4) Игровой поток данных

- [ ] Во время матча приходят события `update`/`death`
- [ ] После завершения матча overlay уходит в empty state (`Ожидание матча...`)
- [ ] Нет зависших старых метрик после конца игры

## 5) Логи и отладка

- [ ] `NUXT_LOG_LEVEL` выставлен под сценарий:
  - `debug` - детальная диагностика
  - `info` - стандартный режим
  - `silent` - минимум шума
- [ ] В серверной консоли нет постоянных ошибок WS/GSI

## 6) Визуальная проверка в OBS

- [ ] Browser Source открывает нужный URL overlay
- [ ] Проверены позиция/масштаб/обрезка виджета в сцене
- [ ] FPS/CPU стабильны на тестовом запуске 5-10 минут
